---
name: Staff profile file categories
description: Product rule for reusing staff file category names without sharing uploaded documents.
---

File category names are reusable across staff profiles within the center; category instances and uploaded files remain scoped to the individual staff member.

**Why:** The user explicitly wants to avoid retyping category names while keeping each employee’s documents private and distinct.

**How to apply:** Reuse the shared name catalog when creating a staff member’s category, but never share or copy another staff member’s attachment records or file access.
