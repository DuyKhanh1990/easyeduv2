---
name: Class session rich-text note
description: A rich-text note belongs to each individual class session in the Education schedule.
---

Each scheduled class session has its own “Ghi chú buổi học” field inside “Nội dung buổi học”. Use the shared rich-text editor so staff can format note text, including size and color; do not merge these notes into the class-wide notes or ordinary content items.

**Why:** The user requested session-specific notes for information relevant to that particular lesson.

**How to apply:** Persist the note on its class session and keep it editable from the selected-session detail card. Preserve other session content and class-level fields.
