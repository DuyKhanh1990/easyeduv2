---
name: Class notification labels
description: Consistent display format for class references in notifications.
---

Show a class as `Class name (class code)` in notifications. If the name is blank, show the code by itself; if the code is blank, show the name.

**Why:** Users often cannot identify a class from its generated code alone, while the code remains useful for cross-referencing.

**How to apply:** When composing in-app, push, or provider notifications that mention a class, use the same name-first format and avoid empty parentheses or duplicate labels.
