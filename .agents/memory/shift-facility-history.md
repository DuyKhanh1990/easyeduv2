---
name: Facility shift history
description: Keep shift rows independent by facility while preserving assignment and attendance history when one is stopped.
---

Shift configuration and assignment rows are independent per facility. Selecting multiple facilities is only a bulk-create convenience: it creates one row per facility, and later edits or stops affect only the selected row. For bulk assignment creation, show one shared schedule and offer only shifts with matching code, name, and start/end times across all selected facilities; save each facility's own template ID. Do not hard-delete assignment or attendance history. Ended assignments must remain available to salary calculations for historical periods, using an inclusive effective end date in Asia/Bangkok.
The shift board displays one row per staff/facility pair only when that facility has at least one assigned shift in the displayed month; keep one row when only one facility qualifies.

**Why:** The user clarified that each facility manages its own rows, requested one shared schedule when bulk-creating assignments, and chose to limit shared choices to shifts that match across all selected facilities. They also requested facility-specific rows on the shift board without changing other schedule rules. Stopping a row must preserve historical assignment and attendance records. Older multi-location edit forms can still submit several entries, so rejecting every multi-entry update can block edits.

**How to apply:** When a user selects multiple facilities during creation, present one shared schedule, map each selection to the matching local shift-template ID, and save separate rows. On the shift board, scope each displayed row's assignments and total to one employee and one facility; do not duplicate a facility row for multiple assignments at that same facility. For later edits, select only the submitted entry for the row's facility and update that row; ignore sibling entries. For deactivation, scope to one row and keep historical queries aware of ended assignments.
