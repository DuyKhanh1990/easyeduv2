---
name: Invoice template editor sizing
description: User's layout preference for the invoice print-template designer.
---

Keep the invoice template dialog split between design and live preview. Make the editable paper use the available width of the design pane and allow vertical scrolling. Scale the preview uniformly to fit its pane. Do not add zoom/fit buttons that consume design space. Screen-only scaling must not change the saved document dimensions or printed A4 output.

**Why:** The user wants more usable editing space and explicitly asked to remove extra controls while retaining the existing side-by-side layout.

**How to apply:** Follow this when adjusting the invoice template editor layout. Keep print CSS and preview output unchanged unless the user separately requests print-layout changes.
